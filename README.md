PROJECT DESCRIPTION:
This project is an AI-powered chatbot developed using Flask as the backend framework, with Natural Language Processing (NLP) techniques integrated using the NLTK library. It is designed to interact with users in a conversational way, answering general knowledge queries and recognizing simple greetings. The chatbot combines the power of WolframAlpha for computational intelligence and Wikipedia for general information extraction.
The front end of the chatbot is created using HTML and CSS, styled with a modern chat interface that mimics common messaging apps. It allows users to type in their questions, which are then sent to the Flask backend through JavaScript's fetch API. The backend processes the input using basic NLP techniques like tokenization (breaking text into words) and greeting detection using NLTK.
When a question is asked, the chatbot first checks if the input contains a greeting word (like "hi", "hello", etc.). If so, it responds with a friendly message. Otherwise, it forwards the query to WolframAlpha. If WolframAlpha cannot provide a result, it falls back to searching Wikipedia and returns a brief summary. If both fail, it responds with an error message.
This system demonstrates the ability of NLP to preprocess natural human language and use APIs to provide meaningful answers. The chatbot is also capable of running both locally and on a local network, making it accessible through different devices on the same Wi-Fi.
The project includes: A responsive HTML/CSS interface
A Flask-based backend (app.py)
NLP-based preprocessing with NLTK
API integration with WolframAlpha and Wikipedia
A script (nltk_download.py) to install required NLTK datasets
A requirements.txt file for easy environment setup
